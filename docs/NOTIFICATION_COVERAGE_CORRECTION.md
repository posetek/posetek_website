## Recorded attempts and identity

The fourteen supported social callables receive a fresh website diagnostic UUID
for each explicit invocation. Caller-supplied request IDs cannot make distinct
invocations the same diagnostic attempt. The wrapper copies the argument object,
replaces only its request reference and retains business fields such as `jobId`.
SDK transport retries within that invocation keep the same copied arguments and
reference. Unrelated callable/auth contracts remain unchanged. Malformed
positional payloads are not rewritten to invent a contract, so their client and
server observations may lack an exact shared reference.

Error-object suppression is bounded and request aware: reusing an Error object
across different scoped attempts records each attempt, while a global rejection
copy of an already captured wrapper failure is suppressed. The durable queue
retains the original account, event, request and occurrence time across intake
retries, including account switches and lost acknowledgements.

The server preserves legacy primary IDs and frozen email permissions. Exact
actor/request evidence can corroborate an occurrence only when its known operation
and authorized target are compatible. Reused references with conflicting known
endpoints, athletes or anonymous sessions remain separate stable occurrences.
Missing context cannot choose between known conflicting branches. Durable
server-owned source claims retain replay identity; bounded branch registries
isolate ambiguous overflow rather than discard it as a duplicate. Source
observations preserve their own provenance and context without replacing the
canonical actor or target. Both arrival orders and all fourteen compatible
endpoint controls are covered by tests.

Authenticated account identity, occurrence-time token evidence, current exact-UID
Auth contact and target athlete remain separate. Auth may supply no display name
or an unverified email. A failed current lookup preserves last-known evidence and
labels the current contact unavailable. A recipient, device, nearby event or
athlete name never fills an unknown actor. A diagnostic uploader identifies the
reporter, not a proven original operator. Automated service and AI failures do not
imply an affected operator without exact evidence.
